# Inmunobio

## Descripción

Inmunobio es una plataforma de gestión integral desarrollada para el laboratorio **CESyMA (Centro de Estudios en Salud y Medio Ambiente)** de la **Universidad Nacional de San Martín (UNSAM)**.

El proyecto nace con el objetivo de centralizar y optimizar los procesos administrativos, científicos y de investigación del laboratorio, proporcionando una herramienta adaptable a las necesidades de los distintos equipos de trabajo.

## Objetivos

- Centralizar la información de proyectos de investigación.
- Gestionar usuarios y roles dentro de la organización.
- Administrar bioterios y recursos asociados.
- Organizar espacios físicos y equipamiento.
- Facilitar la documentación y trazabilidad de procesos.
- Mejorar la comunicación entre investigadores y colaboradores.
- Incorporar herramientas de facturación y seguimiento presupuestario.

---

## Problemática

Los laboratorios de investigación suelen manejar grandes volúmenes de información distribuidos entre diferentes sectores, herramientas y responsables.

La falta de centralización genera:

- Dificultad para acceder a la documentación.
- Seguimiento limitado de proyectos.
- Problemas de coordinación entre equipos.
- Falta de visibilidad sobre recursos y espacios disponibles.
- Procesos administrativos poco automatizados.

Inmunobio fue diseñado para resolver estos desafíos mediante una plataforma integrada y modular.

## Funcionalidades Principales

### Gestión de Proyectos

- Registro de proyectos de investigación.
- Seguimiento de avances.
- Asignación de responsables.
- Administración de participantes.

### Gestión de Usuarios

- Control de acceso basado en roles.
- Administración de permisos.
- Información centralizada de usuarios.

### Gestión de Espacios

- Organización de espacios físicos.
- Registro de disponibilidad.
- Gestión de recursos asociados.

### Bioterio

- Registro y seguimiento de animales.
- Gestión de cuidados y controles.
- Vinculación con investigaciones y protocolos.

### Facturación y Presupuestos

- Registro de movimientos financieros.
- Seguimiento presupuestario.
- Control administrativo.

### Documentación

- Centralización de archivos.
- Acceso rápido a información relevante.
- Trazabilidad documental.

## Metodología de Diseño

Durante la etapa de análisis se utilizaron:

### DTIU

Diagramas de Transición entre Interfaces de Usuario (DTIU) para modelar:

- Navegación entre pantallas.
- Estados del sistema.
- Acciones del usuario.
- Flujos de interacción.

### Casos de Uso

Se documentaron más de 37 casos de uso para definir:

- Objetivos funcionales.
- Actores involucrados.
- Escenarios principales.
- Caminos alternativos.
- Reglas del negocio.

## Arquitectura del Proyecto

### Frontend
